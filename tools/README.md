# How this site is put together

Static site on GitHub Pages (`.github/workflows/static.yml` deploys `main` on every push).

| What | Where |
|---|---|
| Availability (open / paused / hidden), rates, discounts, analytics IDs | `assets/site-config.js` — edit with **Site Manager.pyw** (double-click) and press **Publish** |
| Pricing engine (seasons, discounts, monthly, quotes, rate cards) | `assets/pricing.js` |
| Shared behaviour (status hooks, "from" prices, reveals, analytics loader) | `assets/site.js` |
| Shared styles for the photo hero, reveals, status ribbons, price cards | `assets/ui.css` |
| Home page | `index.html` (its own inline CSS + JS, plus the shared files above) |
| Property pages, Things to Do, Monthly Stays, Book Direct | generated by `tools/gen_pages.py` — **edit the copy there and re-run it**, don't edit those `index.html` files directly |
| Six hand-written area guides | `<slug>/index.html` (use `assets/site.css` + `assets/guides.css`) |
| Crawler-visible bits that mirror the config (JSON-LD price range) | `tools/render_static.py` (Site Manager runs it on Save) |
| Booked dates from Airbnb/Google calendars | `.github/workflows/sync-availability.yml` → `availability.json` every 3 hours |
| Booking inquiries | Formspree form in `index.html` (`#bookingForm`) |

## Everyday changes

* **Pause or hide a home / change prices:** Site Manager → Save → Publish.
* **Change page copy:** edit `tools/gen_pages.py` (new pages) or the guide `index.html` files, then
  `python tools/gen_pages.py`, commit, push.
* **Photos:** add `.webp` files to `img/`, reference them in the index galleries (the property pages copy their
  galleries from `index.html` when `gen_pages.py` runs).
* **Reviews count / rating:** `RATING` and `REVIEWS` at the top of `tools/gen_pages.py`, plus the announcement
  bar / hero / schema in `index.html` and the guide pages.

## Checks before publishing by hand

```
python tools/render_static.py      # validates the config and syncs index.html
python tools/gen_pages.py          # regenerates the five generated pages
```
